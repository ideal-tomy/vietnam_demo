# マッチワークス — 人材紹介管理デモ

応募者・紹介先企業・マッチング・選考進捗を一元管理するデモアプリケーションです。

## 機能

- **ダッシュボード** — KPI と選考ファネルの可視化
- **応募者DB** — 応募者の検索・追加・詳細表示
- **紹介先DB** — 求人企業の管理
- **マッチング** — スキル・年収・業界・勤務地・経験に基づく適合度スコア（100点満点）
- **進捗管理** — カンバン形式の選考ステージ管理

## ローカル開発

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開いてください。

## ビルド

```bash
npm run build
npm run preview
```

## デモの制限事項

- データはブラウザ内のメモリのみ（リロードでリセット）
- 認証なし（URL を知っている人は誰でもアクセス可能）
- サンプルデータはデモ用の架空データです
